# TalkTally v1.0 · 交互原型

原型本体是单文件、零依赖、离线可用的 HTML。

- **在线**：GitHub Pages 地址 [https://microstonedev.github.io/TalkTally/](https://microstonedev.github.io/TalkTally/)
- **本地**：打开仓库根目录的 `index.html`，不需要服务器、不需要构建
- **源码位置**：原型即仓库根目录的 `index.html`（为配合 GitHub Pages 直接作为站点首页，已从本目录移出）；本目录保留界面截图与使用说明

## 原型里有什么

| 界面 | 内容 |
|---|---|
| 记录（首页） | 日期与今日统计、话术 chip、按住说话的 FAB、最近记录（含解析路径徽标） |
| 录音浮层 | 声波动画、逐字出现的转写文本、“松手入账 · 上滑取消”提示 |
| 解析卡片 | 本地规则 / 云端解析徽标与延迟、可编辑的金额·分类·账户·备注（备注默认保留完整原话）、一句话拆两笔、口误纠正（修改详情写入备注） |
| 流水 | 年月切换（‹ ›）、全部/支出/收入筛选、按日分组与每日收支小计、解析路径徽标 |
| 复盘 | 周次切换（‹ ›）、三种对比基准（上周/近4周均值/近12周最高）、近 8 周按分类堆叠的支出柱状图与图例、月预算进度、分类构成、AI 建议 |
| 设置 | 云端解析开关、本机加密开关、导出 CSV / JSON（真实下载）、导入账单 CSV |

支出分类共 13 类：餐饮、交通、购物、日用、娱乐、居住、医疗、学习、人情、通讯、旅行、宠物、其他。流水圆点、分类构成条、周对比堆叠柱使用同一套配色。

## 演示路径（建议按这个顺序点）

1. 首页点橙色的 chip，例如「星巴克咖啡38，微信支付」→ 卡片显示**本地规则 · 7ms**，备注默认保留完整原话；
2. 点「昨天外卖40，室友转我20」→ 卡片变成**云端解析 · 486ms**，出现数据最小化说明，并拆成支出 40 与收款 20 两笔；
3. 入账后去「流水」：用顶部 ‹ › 切换年月，用「支出/收入」筛选，看数据联动；
4. 去「复盘」：用 ‹ › 翻到其他周，切换「上周/近4周均值/近12周最高」三种对比基准，看柱状图、分类构成和 AI 建议如何随之变化；
5. 去「设置」关掉云端解析，再回首页点「昨天外卖40，室友转我20」→ 得到“没听懂这句 · 可手动补全”的降级卡片；此时点「打车25」仍能走本地规则入账；
6. 点「把刚才那笔改成32」→ 演示口误纠正：确认后这笔的备注会追加「｜语音修改：金额 ¥26.5→¥32（日期 时间）」，在流水里可追溯；
7. 「设置」里点导出 CSV / JSON，得到真实可用的文件；「上个月花呗耳机分12期」会带 v0.2 分期标记。

## 与产品文档的对应

原型实现的是 PRD（`../PRD.md`）v1.0 范围：两层解析（本地规则表 + 云端兜底）、数据最小化三原则、本地账本、一键导出、周报建议。共享账本、分期计划、多币种在原型里只以 V0.2 标记出现，未做实现。

## 原型边界（重要）

这是**前端行为原型**，用于验证交互与信息架构，不是可运行的 App：

- 语音是话术 chip 模拟的，没有接真实语音识别；解析是前端内置的规则表与样本，没有接真实大模型服务；
- 账本数据存在页面内存里，刷新即还原为示例数据；导出的文件内容是这份示例账本；
- 深色视觉与海报（`../poster/`）同一套设计语言：深海军蓝底、单一橙色强调。
